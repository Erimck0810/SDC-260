Features for Nomad Life Gallery are as follows 

Home Page- hero banner + featured works grid, CTA into Browse.
Browse Page- full catalog grid with sidebar filters (title/artist search, medium dropdown, verified-only toggle), one-click add to cart.
Artists Page- artist directory: avatar, location, work count, expandable bio, link to that artist's filtered work.
Technology Page- 4 explainer cards (provenance, storage, royalties, hardware) with click-to-expand detail.
My Collection Page- saved/owned items dashboard with running stats, one button to bulk-add everything to cart and jump to checkout.
Cart Page- quantity steppers, remove line items, live running total, clear cart.
Checkout Page- shipping + payment form with live input formatting (card number, expiry, phone), inline validation, coupon codes with real discount math.
Contact Page- validated contact form with status feedback.
Network-Test Page- small diagnostic page (host/port/protocol/last-launch), linked quietly in the footer.
